在电表行业中，晶振老化是一个**缓慢变化过程**，而网络授时数据则包含**随机高频噪声**。卡尔曼滤波（Kalman Filter）的精髓在于：它不只是简单的平均，而是根据**模型预测的确定性**（协方差 $P$）与**观测数据的确定性**（测量噪声 $R$）来动态分配权重。

针对电表 MCU 资源有限的特点，我们通常使用**标量版（1D）卡尔曼滤波**来实时估算老化系数 $A$。

---

## 1. 卡尔曼滤波五个核心方程的简化应用

在老化补偿场景下，状态变量即为我们要修正的 $AgingFactor$（记为 $x$）。

|**步骤**|**方程 (LaTeX 修正)**|**物理含义**|**电表工程逻辑**|
|---|---|---|---|
|**1. 状态预测**|$x_{k \mid k-1} = x_{k-1}$|**预测当前老化程度**|认为当前的老化因子与上一时刻基本一致。|
|**2. 协方差预测**|$P_{k \mid k-1} = P_{k-1} + Q$|**评估预测不确定度**|随时间推移，模型预测的信心会因为 $Q$（过程噪声）而下降。|
|**3. 计算增益**|$K_k = \frac{P_{k \mid k-1}}{P_{k \mid k-1} + R}$|**分配信任权重**|$K$ 决定了你是更相信“模型预测”还是更相信“传感器测量 ($z_k$)”。|
|**4. 状态更新**|$x_k = x_{k \mid k-1} + K_k(z_k - x_{k \mid k-1})$|**修正老化因子**|根据测量残差（误差）来微调最终的老化输出。|
|**5. 协方差更新**|$P_k = (1 - K_k)P_{k \mid k-1}$|**更新置信度**|本轮修正完成后，系统的不确定度 $P$ 会减小。|

---

## 2. 关键参数 $Q$ 与 $R$ 的取值准则

在电表工程中，这两个参数决定了滤波器的“性格”：

- **测量噪声 $R$ (Measurement Noise):** 反映授时精度。
    
    - 若是高精度 NTP（误差 < 10ms），$R$ 设小一点。
        
    - 若是长间隔基站对时（误差 > 100ms），$R$ 设大一点，让系统表现得更“迟钝”以过滤波动。
        
- **过程噪声 $Q$ (Process Noise):** 反映老化模型的不确定性。
    
    - 电表通常设得极小（如 $1 \times 10^{-7}$），因为老化系数 $A$ 不可能在短时间内突变。

## 4. 工业级 C 语言实现 (针对 MCU 优化)

为了避免浮点运算开销，建议在计算 $K$ 时保留足够的有效位数：

C

```
typedef struct {
    float x; // 估计值 (AgingFactor)
    float p; // 估计协方差
    float q; // 过程噪声
    float r; // 测量噪声
} KalmanState;

float kalman_update(KalmanState *state, float measurement) {
    // 1. 预测 (简单模型：x保持不变)
    state->p = state->p + state->q;

    // 2. 计算卡尔曼增益
    float k = state->p / (state->p + state->r);

    // 3. 更新估计值 (融合实测值)
    state->x = state->x + k * (measurement - state->x);

    // 4. 更新协方差
    state->p = (1.0f - k) * state->p;

    return state->x;
}
```

## 5. 总结：为什么要用卡尔曼而非普通平均？

1. **自适应权重：** 当电表刚挂网时，我们将初始 $P$ 设大，系统会快速学习（相信观测）；运行一年后 $P$ 变小，系统进入稳定维护期（相信模型），不再被偶尔的网络抖动带偏。
    
2. **最优性：** 在高斯白噪声假设下，卡尔曼滤波是方差最小的线性无偏估计，是目前工业级授时设备处理时钟漂移的“金标准”。
