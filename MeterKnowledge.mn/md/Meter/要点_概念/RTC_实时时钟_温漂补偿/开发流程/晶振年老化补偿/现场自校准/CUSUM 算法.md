CUSUM（Cumulative Sum，累积和）

CUSUM 通过累加实测值与预测值之间的残差来放大微小的趋势变化。在电表工程中，我们通常使用**双边 CUSUM**，分别监测正向和负向的偏移。

### 核心公式

设第 $k$ 次对时的残差为 $y_k$，系统容忍的噪声水平（松弛因子）为 $g$。我们维护两个累积量 $S_H$（高位偏移）和 $S_L$（低位偏移）：

- **高位累积：** $S_H(k) = \max(0, S_H(k-1) + y_k - g)$
    
- **低位累积：** $S_L(k) = \max(0, S_L(k-1) - y_k - g)$
    

### 判定准则

当 $S_H$ 或 $S_L$ 超过设定的阈值 **$H$** 时，判定发生**频率跳变**，而不是坏点。


利用 **CUSUM（Cumulative Sum，累积和）** 算法检测频率跳变，本质上是从“关注单次误差”转向“关注误差的长期趋势”。

当晶振发生频率跳变（Step Change）时，单次的卡尔曼残差可能被误认为坏点（Outlier）而被残差监测器剔除。但与随机噪声不同，跳变会导致残差**持续偏向同一侧**。CUSUM 正是捕捉这种“微小但持久”偏移的神器。

## 3. 工业级 C 语言实现

在 MCU 中，CUSUM 算法极其轻量，只需要两个静态变量。

C

```
#define CUSUM_G  0.2f  // 松弛因子：需略大于正常噪声的 1 sigma
#define CUSUM_H  3.0f  // 报警阈值：值越大，误报越少，但检测延迟越高

typedef struct {
    float s_h; // 正向累积和
    float s_l; // 负向累积和
} Cusum_t;

/**
 * @return 0: 正常, 1: 频率正向跳变, -1: 频率负向跳变
 */
int8_t cusum_check(Cusum_t *state, float residual) {
    // 更新累积和
    state->s_h = fmaxf(0.0f, state->s_h + residual - CUSUM_G);
    state->s_l = fmaxf(0.0f, state->s_l - residual - CUSUM_G);

    if (state->s_h > CUSUM_H) {
        state->s_h = 0; // 触发后重置
        return 1; 
    }
    if (state->s_l > CUSUM_H) {
        state->s_l = 0;
        return -1;
    }
    return 0;
}
```

## 4. 坏点 vs. 跳变的区分逻辑

将 CUSUM 与你之前的残差监测（$\sigma$ 准则）结合，形成完整的工业级判定链：

| **现象**   | **残差监测器 (3σ) 表现**                | **CUSUM 表现** | **系统决策**            |
| -------- | -------------------------------- | ------------ | ------------------- |
| **正常噪声** | $\vert y_k \vert < 3\sigma$      | 保持在 0 附近     | **信任模型**：继续平滑滤波     |
| **突发坏点** | $\vert y_k \vert > 3\sigma$ (单次) | 略微上升但未过阈值    | **抑制坏点**：抛弃该点，不更新状态 |
| **频率跳变** | 持续出现 $\vert y_k \vert > 3\sigma$ | 迅速累积并超过 $H$  | **重置模型**：判定为物理跳变    |

> **关键经验：** 当 CUSUM 触发后，不要只是接受那一个点，而是应该将卡尔曼滤波器的协方差 $P$ **瞬间放大 10-100 倍**。这会迫使滤波器承认“旧的模型已经失效”，从而在接下来的几次对时中快速吸纳新数据。
