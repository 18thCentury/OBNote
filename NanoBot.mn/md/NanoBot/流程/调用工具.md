以

**OpenClaw** 是一个强调“极简”和“高性能”的 LLM Agent 框架。它模拟了类似 OpenAI Function Calling 的机制，但通过精心设计的 Prompt 引导 LLM 进行**思考（Thought）和行动（Action）**。

下面我为你演示一个完整的流程：用户询问天气，Agent 调用 `get_weather` 工具并返回结果。

---

### 1. 角色定义与工具准备 (System Prompt)

在 OpenClaw 中，一切始于系统提示词。我们需要告诉 LLM 它有哪些工具可用，以及必须遵守的输出格式（通常是 JSON 或特定标签）。

**System Prompt 示例：**

> 你是一个集成各种工具的 AI 助手。请根据用户需求调用工具。
> 
> **可用工具列表：**
> 
> - `get_weather(city: str)`: 获取指定城市的实时天气。
>     
> 
> **响应格式：**
> 
> 如果需要调用工具，请输出：
> 
> `Thought: <你的思考过程>`
> 
> `Action: {"name": "get_weather", "parameters": {"city": "上海"}}`
> 
> 如果直接回答，请输出：
> 
> `Final Answer: <回答内容>`

---

### 2. 第一轮：LLM 生成调用指令 (LLM Output)

**用户输入：** “帮我看看上海现在的天气怎么样？”

**LLM 生成的 Response：**

Plaintext

```
Thought: 用户想要了解上海的天气。我有一个 get_weather 工具可以获取实时数据。
Action: {"name": "get_weather", "parameters": {"city": "上海"}}
```

---

### 3. 中间层：OpenClaw 执行工具 (Tool Execution)

此时，OpenClaw 框架会解析上述 `Action` 字段，在本地执行 Python 代码：

Python

```
# OpenClaw 内部执行伪代码
def get_weather(city):
    # 模拟 API 调用
    return {"temp": "25°C", "condition": "晴朗"}

observation = get_weather("上海")
```

---

### 4. 第二轮：将观测结果反馈给 LLM (Observation Prompt)

OpenClaw 会将工具执行的结果拼接到对话历史中，再次发送给 LLM。

**发送给 LLM 的新 Context：**

Plaintext

```
... (之前的对话历史) ...
Action: {"name": "get_weather", "parameters": {"city": "上海"}}
Observation: {"temp": "25°C", "condition": "晴朗"}
```

---

### 5. 最终轮：LLM 给出答案 (Final Response)

LLM 看到 `Observation` 后，理解任务已完成，给出最终结论。

**LLM 生成的 Response：**

Plaintext

```
Thought: 我已经获取到了上海的天气信息（25°C，晴朗），现在可以回答用户了。
Final Answer: 上海现在天气晴朗，气温大约是 25°C，非常宜人。
```

### 流程总结图

### 核心代码实现逻辑 (Python)

如果你想用 Python 快速理解 OpenClaw 的核心逻辑，它其实就是一个 `while` 循环：

Python

```
history = [{"role": "system", "content": SYSTEM_PROMPT}]

def run_agent(user_input):
    history.append({"role": "user", "content": user_input})
    
    while True:
        # 1. 调用 LLM
        response = llm.chat(history) 
        
        # 2. 解析 Action
        if "Action:" in response:
            action_data = parse_json(response) # 解析出工具名和参数
            
            # 3. 执行工具 (Observation)
            result = execute_tool(action_data['name'], action_data['parameters'])
            
            # 4. 将结果喂回历史，继续循环
            history.append({"role": "assistant", "content": response})
            history.append({"role": "system", "content": f"Observation: {result}"})
        else:
            # 5. 直到出现 Final Answer，退出循环
            return extract_final_answer(response)
```
